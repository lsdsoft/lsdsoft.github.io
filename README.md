# Call Screening Agent — Public Documentation & Privacy Policy

This repository hosts the official publicly accessible Privacy Policy web page for **Call Screening Agent**, an Android application developed by **LSD Software**.

---

## 📄 Privacy Policy Overview

**Call Screening Agent** is built with user privacy as a foundational principle. The application operates using a **100% local processing architecture**, ensuring that sensitive telephony data never leaves the user's device.

### Key Privacy Principles
* **Local Data Storage:** All blocked call logs and custom whitelists are stored strictly on-device using a local Room database and `SharedPreferences`.
* **Zero External Data Transmission:** No phone numbers, call history, or contacts are ever uploaded, sold, or shared with external servers or third-party entities.
* **Granular Permission Usage:** The application utilizes Android's native `ROLE_CALL_SCREENING` to process incoming calls directly on-device and `ACTION_PROCESS_TEXT` for seamless system-wide whitelist management.
